This tool uses the same algorithm as github-readme-stats. With a GitHub token, Auto Mode uses the GraphQL API (identical to github-readme-stats) for exact results.

CDF Functions

exponential_cdf(x) = 1 - 2-x log_normal_cdf(x) = x / (1 + x)

Weights

Stars(4) + PRs(3) + Commits(2) + Issues(1) + Followers(1) = 11

Score

score = weighted_sum / 11 percentile = (1 - score) × 100
